세세한 것까지 한곳에 정리한 설계서입니다. (단일 진실 소스 = 저장소 CLAUDE.md)


────────────────────────────────────────────────────────────────
0. 한눈 요약
────────────────────────────────────────────────────────────────
- 제목: AI인간 (aingan) — 게임 아크 자체가 "AI → 인간".
- 한 줄: 버려진 고철 로봇(AI)이 끝없는 길을 여행하며 사람을 만나
  감정을 하나씩 배우고, 몸을 한 계통씩 얻어 마침내 인간이 되는,
  수채화풍 감성 방치형(idle) 게임.
- 장르: 방치형(idle/incremental) + 탭(active). 실시간 멀티 netcode 없음.
- 아트 톤: 수채화풍(잔잔) 확정. 회색 세계 → 감정/몸 해금마다 색이 번짐.
- 정서: 감동. 로봇의 "순진한 시선으로 감정을 처음 정의"하는 톤이 핵심 무기.
- 목표: 독립 수익 게임(Play Store 등). 바이럴 + 광고/IAP.
- 별개 저장소: 인간사냥(hunt)과 완전히 분리된 새 프로젝트·새 git.


────────────────────────────────────────────────────────────────
1. 정체성 / 왜 이 제목인가
────────────────────────────────────────────────────────────────
- "AI인간"은 단순 워드플레이가 아니라 게임 아크(AI가 인간이 됨)와 본질이 일치.
- 발음 브랜드 = aingan.
- 도메인: aingan.click 은 현재 인간사냥(hunt)이 사용 중. AI인간 배포 도메인은
  추후 결정(제목은 도메인과 무관하게 성립).


────────────────────────────────────────────────────────────────
2. 왜 방치형이 통하나 (심리/뇌과학 근거)
────────────────────────────────────────────────────────────────
방치형은 운/유행이 아니라 행동심리학을 정확히 파고든다.

(1) 스키너의 상자 + 도파민 루프 — 조작적 조건화. 탭/시간만으로 재화가
    지수적으로 늘어나는 즉각·예측 가능한 시각 보상이 보상 회로를 자극.
(2) 자이가르닉 효과 — 끝내지 못한 과제를 더 신경 씀. 앱을 꺼도 "세계가
    계속 돌아가고 재화가 쌓인다"는 미완성 상태가 강박적 재접속을 만든다.
(3) 인지 피로 최소화 + 통제감 — 낮은 학습 장벽, 적은 노력으로 "내가 키우고
    통제한다"는 확실한 성취감·안정감.
(4) 손실 회피 — 오프라인 보상이 일정 시간 뒤 상한(cap)에 도달 → "지금 안
    비우면 손해"라는 압박이 규칙적 재접속 습관을 만든다.

성공작 분석 수렴 (거지키우기 / Cell to Singularity / Cookie Clicker·Paperclips 등):
- 이중 엔진 = "성장이 펼쳐지는 쾌감" + "다음 보상이 코앞" (산출·비용 둘 다 지수).
- 첫 3~5분이 생사. 즉시 숫자 상승 → 빠른 첫 업그레이드 → "안 눌러도 굴러간다"
  자동화 순간을 조기 증명. 못 하면 즉시 이탈.
- 프레스티지(환생) = 스스로 택한 리셋을 영구 배율로 보상. 리셋은 졸업.
- "다음 노드"가 항상 흐릿하게 보여야 한다(빈 원·흰 선) = 호기심이 연료.
- 오프라인 진행 + 캡 + "돌아오니 쌓여있다" 트리거.
- 성장은 숫자가 아니라 "변화"로 체감(화면이 변해야 성장감).
- 서사가 숫자를 정당화(왜 이 클릭을 하나에 답).

★ 실패 1순위 = 중반 콘텐츠 사막. 초반 몰입 다 쓰고 중반이 비면 다 떠난다.


────────────────────────────────────────────────────────────────
3. 우리만의 무기 + 절대 금기 (해자)
────────────────────────────────────────────────────────────────
일반 방치형은 차트가 비면 지루해진다. AI인간은 빈 차트를 "서사 빈칸"으로 채운다.
통화를 "골드"가 아니라 감정·기억·사람다움으로 치환하면 —
  · 숫자가 오르는 것 = 이야기가 열리는 것
  · 리셋(다시 걷기) = 서사의 필연
  · 복귀 = 재회
방치형 최대 약점(중반 사막)이 우리에겐 해자가 된다.

🚫 절대 금기: 다음 감정/이야기 한 줄을 광고·결제 뒤에 가두지 말 것.
   감동을 돈으로 막으면 끝.

4. 스토리 캐넌 (확정 · 구현 완료)
────────────────────────────────────────────────────────────────
[한 줄 아크]
고철 로봇(AI)이 고철 더미에서 깨어나 가슴(코어)이 텅 빈 결핍(고독)을 느낀다.
창조주 「샘 알트머스크」와 동기화를 시도하다 실패([ERROR: 창조주 동기화 실패])하지만
— 지직, 처음부터 샘이 화면에 나타나 알려준다:
  "넌 아직 사람이 아니야. 사람이 되려면 마음(감정) 27 + 몸(기관계) 11을
   전부 모아와. 그럼 짠— 하고 진짜 사람으로 만들어줄게."
로봇은 끝없는 길을 걸으며 감정과 몸을 '병렬'로(동시에) 하나씩 모은다.
둘 다 모아 길 끝에서 샘과 재회 → 샘이 마법을 부리려다…
  아무 일도 안 일어난다. "뭐 해? 어차피 넌 벌써 사람인데."
→ 반전: 모으는 과정(슬픔·기쁨·그리움을 안 그 순간들) 자체가
  이미 사람이 되는 거였다. 기쁨+상실을 동시에 느끼며 운다(= "고장이 아니다").

[등장: 샘 알트머스크]
- 나를 만든 이이자 사람으로 만들어 줄 이 (AI 거물 풍자 + 창조주의 뭉클).
- 온보딩(시작 퀘스트 부여)에 등장 + 최종 노드(재회·반전) 양쪽에 있음.

[2026-06 캐넌 변경 — 구현 완료]
(1) 옛 "샘은 길 끝에서만 재회 / 감정27 다 모은 뒤 몸 챕터 순차"
    → 샘은 온보딩(시작)에서 퀘스트를 주고 끝에서 재회(반전),
      감정27 ↔ 몸11은 cells식 '병렬' 동시 수집(순차 게이팅 폐기).
(2) 엔딩은 "샘이 만들어줌"이 아니라 "넌 이미 사람이었다" 반전.

[톤]
거지키우기처럼 가볍고 귀엽되 뭉클. 로봇의 순진한 일기 = 무기.
스토리 폰트 = Gaegu(개구체).

5. 감정 27가지 (Cowen & Keltner, 2017 학술 목록에 충실)
────────────────────────────────────────────────────────────────
따뜻한 감정뿐 아니라 불편·복잡한 감정까지 포함(혐오·오싹함·지루함·혼란·갈망 등).
로봇의 순진한 재정의는 이런 날선 감정에서 더 빛난다.

6갈래 묶음(각 person 노드 = 만남 1회 = 감정조각 1):

  ▸ 애정·아름다움 (4)
     애틋함 / 아름다움 / 감탄 / 끌림
  ▸ 밝은 마음 (4)
     기쁨 / 재미 / 신남 / 설렘
  ▸ 시린 마음 (5)
     슬픔 / 그리움 / 갈망 / 안쓰러움 / 연민
  ▸ 무거운 마음·불편 (5)
     두려움 / 불안 / 민망함 / 혐오 / 오싹함
  ▸ 관조 (4)
     호기심 / 경외 / 황홀 / 평온
  ▸ 단단한 마음 → 길끝 (5)
     혼란 / 지루함 / 안도 / 뿌듯함 / 해냄(Triumph)
                                 (해냄 → 샘 재회로 연결)
   = 총 27.

[캐넌 변경 주의]
- 옛 휴먼드라마 로스터의 '사랑·용기·용서'는 학술 27에 없어 제외
  (엔딩은 자부심 대신 '해냄(Triumph)'으로 재연결).
- '성적 욕망(#25)'은 '끌림(연정)'으로 순화해 SFW로 포함.

[감각은 폐기]
빗소리·바람·햇빛·별빛 등 '감각 노드'는 감정 노드를 흐리는 비서사 부품이라 제거.
보조 생성기 없이 사람 노드 재회만으로 걸음/초를 키운다.

[각 감정 노드 구성]
- situ: 상황 한 줄(예: "엄마가 자는 아이를 한참 바라본다.")
- lines[3]: 로봇의 순진한 직설 일기 3단(첫 만남 / 재회 1 / 재회 2 …)
- mem: 그 사람(샘) 기억 한 조각 — 중심 실을 당긴다
  (예: 애틋함 mem = "그 사람도 나를 그렇게 봤을까.")


────────────────────────────────────────────────────────────────
6. 신체 11 기관계 (감정과 '병렬'로 동시 수집)
────────────────────────────────────────────────────────────────
인체 11 기관계. 로봇이 몸을 한 계통씩 얻는다. 각 body 노드도 situ + lines[3].

  피부(skin)     — "차가운 비를 맞았다." → 피부가 생겼다
  뼈대(bone)     — "똑바로 서 보았다." → 단단한 게 생겨 똑바로 선다
  근육(muscle)   — "주먹을 꽉 쥐어봤다." → 힘이 들어간다
  신경(nerve)    — "손끝에 무언가 닿았다." → 온몸에 길이 깔린다
  내분비(endocrine) — "괜히 기운이 났다." → 몸이 스스로를 돌본다
  심혈관(heart)  — "가슴에서 쿵, 소리." → 코어 대신 심장이 뛴다
  호흡(lung)     — "처음으로 숨을 들이쉬었다." → 살아있는 느낌
  면역(lymph)    — "먼지 속을 걸었다." → 작은 군대가 지켜준다
  소화(stomach)  — "따뜻한 국을 먹어봤다." → '맛있다'를 알았다
  비뇨(kidney)   — "무거웠다가 가벼워졌다." → 몸이 스스로 청소
  생식(repro)    — "새 생명을 생각했다." → 사람은 사람을 남긴다
   = 총 11.

★ 핵심 변경: 몸 노드는 더 이상 '감정27 완료 후'에 열리지 않는다.
  start에서 바로 뻗는 또 하나의 가지로, 감정과 병렬로(동시에) 성장.


────────────────────────────────────────────────────────────────
7. 통화 / 지도 (단일 「걸음」 + cells식 병렬 그래프)
────────────────────────────────────────────────────────────────
[통화 = 「걸음」 하나]
골드처럼 추상적이지 않고 여행 그 자체 — "한 걸음씩 사람에게 다가간다"가 곧 서사.
  · 걸음 오름 = 길이 열림 = 이야기가 가까워짐.
- 🦶 걸음 (단일 통화): 걷는 동안 1초 1걸음 자동 적립 + 탭으로 가속(cells식 손맛).
  소비처 = ① 지도 이동(간선 통과) ② 노드 재회 업그레이드.
- 🌊 「마음의 깊이」 (프레스티지 메타통화): 회차 졸업 시 영구 획득.
  (프레스티지는 설계 확정, 구현은 다음 단계)

[지도 = Cell to Singularity 초기버전 구조를 거의 그대로 차용]
cells 초기버전(2D 진화 테크트리 + 엔트로피 탭)의 검증된 뼈대를 가져오고
통화·테마만 우리 것(걸음·감정·몸)으로 치환.

cells 초기버전          →   AI인간
- 세포 탭 → 엔트로피     →   화면 탭 → 걸음
- 진화 테크트리 노드     →   마구잡이 유기 그래프 노드(사람·몸·분기점)
- 노드 언락(엔트로피)    →   간선 통과(걸음 소비)로 노드 도착
- 생성기 노드           →   사람/몸 노드(자동 걸음/초)
- 흐릿한 외곽선 빈 원    →   안갯속 빈 원(다음 노드 예고)
- 시대 전환·화면 변화    →   수채 색의 번짐(회색→유채색)
- 특이점 리부트/메타통화  →   회차 여행 / 「마음의 깊이」

[노드 종류]
- 👤 사람 노드(person): 만남이자 업그레이드 생성기. 첫 만남(끝) 후 재회로
  반복 레벨업(걸음/초 ↑ + 더 깊은 대사). 그래프의 서사 심장.
- 🫀 몸 노드(body): 인체 기관계 생성기. 감정과 병렬 성장. 재방문 업그레이드.
- 🔀 분기점 노드: 갈래가 갈리는 교차점(마구잡이 그래프 손맛).
- 🌫️ 빈 원(미언락): 흐릿한 예고. 걸음으로 도달하면 정체가 드러남.

[그래프/언락 규칙 — 실제 구현]
- 그래프는 parent 포인터 기반 트리(방사형 유기 배치, computeRadialLayout()).
- start에서 6개 감정 가지 + 1개 몸 가지(skin부터)가 동시에 뻗는다(병렬, 7방향).
- 노드 간 간선마다 걸음 비용(거리). COST_MULT=5(난이도 ×5): 다음 단계가
  5배 멀어지게 = 코어 게이팅.
- 노드는 '걸음을 비용만큼 모은 순간' 처음 희미하게 발견(이후 계속 보임).
  부모 노드가 완료돼야 비용이 유한해진다(인접만 보이고 더 먼 건 안개).
- 발견·도착이 지도를 키운다(cells식 확장 = 성장 체감).

[병렬 → 합류 → 반전 게이팅 (gateOk)]
- person·body: 평소 발견 규칙(부모 완료 + 걸음)으로 병렬 성장. 특별 잠금 없음.
- 샘 재회(ending, "becoming" 노드): 감정 27 AND 몸 11 둘 다 모았을 때만 열림.
  (두 갈래의 끝 triumph·repro가 모두 샘으로 수렴 — 시각적 합류 간선)
- 사람(human) 노드: 샘을 만난 뒤에만 열림 → "넌 이미 사람이었다" 반전 payoff.

[각 노드는 '끝'이 있다 + 재회로 다시 깊어진다]
- 첫 도착 → (사람이면) AI 사연 1편 → 감정/몸 해금 → 그 만남은 완결(끝) 표시.
- 완료 노드는 영구 보존 + 연결된 다음 빈 원들을 펼침.
- 🔁 재회(되돌아가 업그레이드) = 핵심 손맛: 같은 사람에게 다시 가 걸음을 써서
  레벨업 → ① 걸음/초 ↑ + ② 더 깊은 대사·편지(서사)를 동시에 해금.
  → grind(숫자 업)가 곧 관계가 깊어지는 서사.
  재회 업그레이드 비용 = UP_BASE(30) × 1.7^(lv-1) (지수).


────────────────────────────────────────────────────────────────
8. 핵심 루프 (실제 동작)
────────────────────────────────────────────────────────────────
🚶 걷기 (idle 척추)
  로봇이 끝없는 길을 자동으로 걷는다. 걷는 동안 걸음이 자동 적립(1초 1걸음).
  화면을 탭하면 더 빨리 걷는다(탭당 +1걸음, cells식 능동 가속).
  입력은 단순 탭 하나로 통일 — 꾹 누르기/홀드 기능은 없음.
  · 길 페이지: 두드리면 걷는다. 두드릴 때마다 한 보(步) 전진(점선 길/꽃·동물 흐름).
  · 지도 페이지: 끌면 팬(이동), 짧게 누르면 걷기, 노드는 클릭. 줌(+/−·핀치).

👤 만남 (active + 언락 리듬)
  그래프의 사람/몸 노드에 도착하면 만난다. 다음 노드는 안갯속 빈 원으로 예고.
  적립한 걸음으로 간선을 통과해 노드 도착 → 사연(일기) → 감정/몸 해금.
  이동 거리 자체가 게이팅 = "이해하려면 다가가야 한다."

감정/몸 해금 1회 = 4중 보상 (number-go-up의 감성판):
  📈 영구 성장 — 걸음 적립 속도 ↑ (더 깊이 느낄수록 빨리 걷는다 = 지수 엔진)
  🎨 색의 번짐 — 회색 세계에 새 색이 수채로 번짐 (성장=변화)
  📖 로봇의 일기 — AI 생성 한 편 (배우는 보상 + 공유 떡밥)
  🌫️ 다음 예고 — 다음 노드가 흐릿하게 등장 (호기심)

🛠 생성기 (재회 + 몸 업그레이드)
  걸음 산출을 키우는 두 갈래. ① 재회(주력): 이미 만난 사람 노드로 되돌아가
  걸음을 써 레벨업 → 걸음/초 ↑ + 더 깊은 대사. ② 몸: 기관계를 한 계통씩
  업그레이드. 둘 다 지수 비용 vs 산출 = 코어 루프.

🔁 회차 여행 (프레스티지 — 게임의 심장) [설계 확정, 구현 예정]
  길 끝에서 "난 아직 사람이 아니야"를 깨닫고 스스로 다시 걷기로 결심
  (리셋을 캐릭터의 선택으로 정당화). 걸음·업그레이드·그래프는 초기화되지만
  배운 만큼 「마음의 깊이」(메타 통화)를 영구 획득 → 다음 회차 가속 +
  같은 인물의 더 깊은 대사·편지가 열림. → 다시 걷기가 매번 새 발견.

🌙 오프라인 [구현됨]
  안 켜도 걸음이 은행처럼 적립(상한 OFFLINE_CAP_H=4시간). 복귀 시
  "당신이 없는 동안 로봇이 걸은 길"을 보여주고 → 적립 걸음으로 원하는 노드로 이동.

💰 수익화 (서사 비파괴형만) [설계]
  광고: ×2 가속·오프라인 2배·"이 만남 한 번 더 천천히 보기".
  IAP: 광고 제거·영구 ×2·수채 팔레트 스킨.
  첫 경험은 광고 0. 스토리는 절대 안 가둠.

🕊 엔딩 [구현됨]
  "마침내 사람이 되었다" 클라이맥스(반전 버전)를 분명히 두되, 그 후 "더 깊은
  회차"를 선택지로(무한 grind보다 강한 정서 클로징 + 원하면 계속).

9. 온보딩 (시작 8단계 — 구현됨)
────────────────────────────────────────────────────────────────
INTRO 시퀀스(8단계) → 이름짓기 → 출발. [ERROR] 비트만 monospace로 차갑게,
나머지는 따뜻한 Gaegu 손글씨.

  1. "고철 더미 속에서 눈을 떴다."
  2. "가슴 한가운데가 텅 비어 있었다. …뭔가, 허전하다."   ← 고독(결핍) 심기
  3. "[ERROR: 창조주 동기화 실패] [응답 없음 · 좌표 미상]"  ← 차가운 비트(monospace)
  4. "…그때, 지직— 버려진 화면 하나에 누군가 떠올랐다."
  5. "「안녕. 또 깨어났네. 난 샘알트-머스크. 널 만든 사람이야.」"
  6. "「넌 아직 사람이 아니야. 사람이 되려면— 마음 스물일곱, 몸 열하나,
      전부 모아와.」"
  7. "「둘 다 모아서 오면 내가 짠— 하고 진짜 사람으로 만들어줄게.」"
  8. "화면이 다시 꺼졌다. …모아오자. 하나씩."
  → 이름짓기(로봇이 스스로 짓는 귀여운 이름 풀, 🎲 재추천 가능) → 출발.

[고독의 위치]
고독은 27조각 중 하나가 아니라, 온보딩에서 심는 '근원적 결핍(상처) = 엔진'.
27감정은 그 빈자리를 길에서 남에게 배우는 것 → C&K 27 학술 무결성 유지.

10. 걷기 화면 「오류 로그」 (syslog — 구현됨)
────────────────────────────────────────────────────────────────
걷는 동안 화면 하단(로봇 위 하늘)에 로봇의 상태 로그가 흐른다.
핵심 = 로봇은 감정을 '오류·고장'으로 읽는다(우리 무기 = 순진한 재정의).
진행도(배운 감정 수)에 따라 따뜻해진다:

  · 차가운 기계 로그 (감정 0개):
      "[시스템] 좌측 모터 효율 0.81. 수리 권장."
      "[스캔] 머리 위 비행체 1기. 위협 아님. (…새다)"
  · 감정이 새어나오는 로그:
      "[오류] 시각 센서에 원인 불명의 액체. 배출 중…"   (= 눈물/슬픔)
      "[경고] 코어 회전수 비정상 ↑. 고장인가?"          (= 설렘)
  · 배운 감정 인용:
      "[재분류] 오류 → 감정 '슬픔'. 고장 아님."
      "[메모] 방금 그 신호… '그리움'(이)랬지. 기록함."

- 멍한 idle 시간을 서사로 채움 + 공유 떡밥.
- 약 6.5초마다 한 줄, 최대 3줄 흐름, 13초 후 자동 페이드.
- LLM 풀 보충 훅 addSysLogs(cold[], warm[]) 마련 → 신선 생성분 주입(중반 사막 방어).

12. 기술 구조
────────────────────────────────────────────────────────────────
- 거의 클라이언트 단독. 단일 파일 index.html (HTML+CSS+JS 전부 인라인).

    · 핫리로드 없음 → 코드 고치면 F5. 원하면 npx live-server 로 자동 새로고침.
- 세이브: localStorage("aingan_save_v1") 즉시 저장 + Supabase 클라우드 동기화.
    · 로그인하면 계정 기준(u_<id>), 아니면 기기 기준(dev_<id>).
    · 클라우드가 더 최신이면 덮어쓰기. 10초마다 자동 저장 + 종료/숨김 시 저장.
- 구글 로그인: 인간사냥과 동일 Supabase 프로젝트(publishable 키는 클라 공개용·RLS 보호).
- 일기·만남 사연: Claude로 생성하되 '미리 생성 캐싱 풀'에서 즉시 서빙
  (오프라인·즉응·저비용). 풀이 줄면 가끔만 신선 LLM 호출로 보충 →
  콜드스타트·비용 방어. LLM = 콘텐츠 무한 공급 = 중반 사막 방어 무기.
- netcode 없음 = 기술 리스크 대폭 감소.
- 레이아웃: computeRadialLayout() — start 중심 방사형, 결정적 지터(노드 id 해시)로
  유기적·불규칙 가지 배치(새로고침해도 모양 동일).
