# 마음을 줍는 로봇 (가제)

> 수채화풍 감성 방치형(idle) 게임 — 버려진 고철 로봇이 끝없는 길을 여행하며
> 사람들을 만나고, 감정을 하나씩 배워 마침내 '사람'이 되는 이야기.

이 저장소는 aingan.click(인간사냥, `projects/ani/demo/hunt`)와 **완전히 별개**인 새 프로젝트다.

## 확정된 방향

- **장르**: 방치형(idle/incremental) + 탭(active). 실시간 netcode 없음.
- **아트 톤**: **수채화풍(잔잔)** 확정. → `mockup/tone-c-watercolor.html`
  - (참고용으로 탈락안 픽사풍도 보관: `mockup/tone-a-pixar.html`)
- **핵심 정서**: 감동. 로봇의 순진한 시선으로 감정을 처음 정의하는 톤.

## 코어 루프 (초안 — 재설계 중)

```
여행(방치 자동 전진) → 만남(사람·사연, AI 생성) → 탭으로 '느끼기'
  → 감정 언락 → 로봇의 일기(AI 생성, 공유 떡밥) → 글로우업(외형이 따뜻해짐)
  → 길의 끝 → 회차 여행(prestige): 더 깊은 마음으로 다시 걷기
```

## 미확정 / 진행 중

- [ ] 방치형 성장 곡선·환생(prestige)·수익화 구조 → **거지키우기·Cell to Singularity 등 성공작 분석 후 확정**
- [ ] 감동 서사와 idle 중독 루프의 결합 방식
- [ ] 제목 확정
- [ ] 기술 스택 (클라 단독 + Supabase 세이브 + 가끔 LLM 호출 예정)

## 기술 메모

- 거의 클라이언트 단독, Supabase로 세이브/랭킹. Render 무료티어 슬립다운 영향 적음(PWA 오프라인).
- 로봇의 일기·만남 사연은 Claude로 생성(가끔 호출, 캐싱 가능 → 저비용).
