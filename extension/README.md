# 강아지 산책 — 타자로 걷기 (크롬 확장 v2)

키보드 **한 글자 = 강아지의 한 걸음**. 아무 사이트에서나 타자를 칠수록 강아지가 걷고,
**걸음을 🦴돈으로 환전**해 강아지를 **꾸민다**. v1(aingan.click, 감정 모으기)과 **완전 독립**.

## 게임 루프

타이핑 → 걸음(steps) → `환전` 버튼(1걸음=1🦴) → 코인 → 🛍 꾸미기 상점에서 액세서리 구매·착용.

## 핵심 원칙

- **개인정보**: keydown '개수'만 센다. 무슨 키인지(`e.key`)는 절대 안 본다 = 키로거 아님.
- **공유**: 백그라운드 + `chrome.storage` 하나가 진실의 원천 → 모든 탭/창이 같은 게임 공유.
- **idle 없음**: 자동 걷기 없다. **키보드 칠 때만** 걷는다 — 친 만큼만 정확히.
- **저장(계정연동)**: `chrome.storage.local`(즉시) + `chrome.storage.sync`(구글 계정에 묶여 기기끼리
  동기화·15초 throttle). 시작 시 `taps`(단조 증가) 큰 쪽으로 병합. (풀 OAuth는 추후.)
- **표시 위치 선택**: 게임 안 토글로 **사이드패널 ↔ 새 탭**.
  - 새 탭 모드: 새 탭 열 때마다 게임(`newtab.html`→`game.html`).
  - 사이드패널 모드: 새 탭은 비운 패스스루, 게임은 툴바 아이콘으로 옆 패널.
  - ⚠️ 새 탭 오버라이드 특성상 설치하면 크롬 기본 새 탭은 이 확장이 점유한다(토글은 게임/패스스루만 결정).

## 크롬에 올리기 (개발자 모드)

1. `chrome://extensions` → 우상단 **개발자 모드** ON
2. **압축해제된 확장 프로그램을 로드** → 이 `extension/` 폴더 선택
3. 새 탭을 열면 강아지(기본=새 탭 모드) / 툴바 아이콘 클릭하면 옆 사이드패널
4. 아무 웹페이지에서 타이핑 → "걸음" 오름 → 환전 → 상점에서 꾸미기

## 설치 못 할 때(DLP·관리정책 등) — 로컬 미리보기

확장 설치/개발자모드가 막혀도, **일반 로컬 웹페이지로 미리볼 수 있다**(`dev-preview.html`).
`chrome.*` API를 가짜로 채워(shim) 게임 코드를 그대로 돌린다 — DLP 우회 아님, 그냥 로컬 페이지.

```bash
python3 -m http.server 8123 --directory <repo>/extension
# 브라우저에서 http://localhost:8123/dev-preview.html 접속 → 아무 키나 치면 강아지가 걸음
```

- 검증됨: 강아지 걷기(키1=걸음+1, 1:1)·배경·상점·환전·페이지펫 전부 동작.
- 한계: 저장이 그 브라우저 localStorage뿐(기기간 sync 아님), 펫은 미리보기 페이지에서만(다른 사이트 X).
- ⚠️ `dev-preview.html`은 DEV 전용 — 웹스토어 zip엔 넣지 말 것.

## 파일

| 파일 | 역할 |
|---|---|
| `manifest.json` | MV3 (storage·sidePanel·newtab override·content_script `<all_urls>`) |
| `content.js` | 모든 페이지 keydown 개수만 카운트 → 1초 배치 전송 |
| `background.js` | 진실의 원천: 걷기·환전·구매·착용 로직 + 상점(SHOP) + local/sync 저장·병합 |
| `game.html/js` | 강아지·걸음·환전·꾸미기 상점 화면(패널·새 탭 공유) + 표시위치 토글 |
| `newtab.html/js` | 새 탭 래퍼. surface 따라 game.html로 교체 or 패스스루 |

## 현재 단계

- **Stage 1 (지금)**: 실사 시바견 누끼 + **키 1번=다리 1번=걸음 +1(1:1)** + 환전 + 꾸미기 상점 5종
  + 표시토글 + 계정 동기화 + **브라우저 펫**(페이지 위를 타자 칠 때 산책, 토글 on/off).
- **다음 후보**: 걸음 부스트 업글(신발=`stepPerKey`↑), 꾸미기 옆모습 배치, 산책 배경.
